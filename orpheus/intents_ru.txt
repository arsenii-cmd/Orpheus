# Сценарии, которые Орфей выполняет сам, без языковой модели: мгновенно и без выдумок.
# Всё, что сюда не подошло, отвечает модель. Что делает каждый сценарий — orpheus/skills.py
# (метод do_<имя раздела>).
#
# Синтаксис (как у Home Assistant, hassil):
#   (а|б)        одно из
#   [а|б]        можно пропустить
#   {слот}       любые слова — их получает сценарий
#   {слот:а|б}   одно из этих слов — его получает сценарий
#   <правило>    кусок, заданный один раз:  <имя> = ...
#   заметк(у|и)  варианты внутри слова
# Регистр, «ё», знаки препинания и вежливые слова вокруг («Орфей, скажи пожалуйста, …») не важны.
# Подходят несколько шаблонов — сначала пробуется тот, где больше своих слов, затем тот, что выше;
# сценарий может отказаться («сколько будет стоить ремонт» — не пример), тогда пробуется следующий.

<сейчас> = [сейчас|щас|теперь|сегодня|на данный момент|у нас|на часах]
<заметку> = (заметк(у|а|и)|заметочк(у|а|и)|запис(ь|и|очку)|памятк(у|а))
<заметки> = (заметки|заметок|заметках|заметочки|записи|записях)
<сделай> = (сделай|сделать|создай|создать|добавь|добавить|запиши|записать|оставь|напиши|сохрани|заведи|черкни)
<про> = (про|о|об|на тему|насчет|по поводу|касательно|с текстом)
<удали> = (удали|удалить|сотри|стереть|убери|убрать)
<прочитай> = (прочитай|прочти|прочитать|зачитай|покажи|перечисли|озвучь|назови|расскажи|открой)
