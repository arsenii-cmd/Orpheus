# Orpheus

**Русский** · [English](README.en.md)

Орфей — голосовой помощник на русском языке, который целиком работает у вас дома: на старом
ноутбуке без видеокарты, без облака и без подписок. Распознавание речи, языковая модель, память и
синтез голоса — всё локально, на CPU. Телефон с приложением для Android служит ему ушами и голосом:
его можно позвать словом «Орфей» или касанием наушника.

```
микрофон → Silero VAD → GigaAM v3 → Ollama (Qwen3 4B) → Piper → динамик
            фразы        текст        ответ + память      голос
```

## Возможности

- **Полностью офлайн.** Интернет нужен только для погоды, поиска и курса валют — и только через
  заданный вами прокси к пяти известным сервисам.
- **Быстро на слабом железе.** Обычные команды выполняет сама программа, без модели: от конца
  фразы до первого звука ответа 0,6–1 с на Ryzen 5 3500U. На всё остальное отвечает языковая модель.
- **Планировщик, заметки, память.** Работает с [Planner](https://github.com/arsenii-cmd/Planner):
  события, задачи и заметки голосом видны и на телефоне, и на компьютере.
- **Только ваш голос.** Отпечаток голоса владельца: телевизор, гости и чужое «Орфей» остаются без ответа.
- **Сам напоминает.** За 15 минут до дела с напоминанием говорит в наушник: «Напоминаю: через 15 минут, в 19:00, — тренировка». Утром первый ответ дня заканчивается сводкой: что впереди, погода и «возьми зонт», если дождь, а в планах пробежка.
- **«Личное».** Отдельная зашифрованная память для личных разговоров; ключ хранится только на телефоне.
- **Приложение для Android.** Фоновая служба, слово активации на устройстве (Vosk), касание
  наушника через системного «цифрового помощника», микрофон Bluetooth-наушников.
- **Установка с флешки.** Один скрипт собирает образ Ubuntu Server, который ставит систему сразу с
  Орфеем и моделями, без интернета.

## Из чего состоит

- **Распознавание:** [GigaAM v3](https://github.com/salute-developers/GigaAM) RNNT с пунктуацией (int8)
  через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx).
- **Мозг:** [Ollama](https://ollama.com), по умолчанию `huihui_ai/qwen3-abliterated:4b-instruct-2507-q4_K_M`
  (Qwen3 4B, ~2,5 ГБ). Проверена и Gemma 4 E4B.
- **Память:** SQLite — факты, заметки и разговоры, поиск по словам и по смыслу.
- **Голос:** Piper (`ru_RU-ruslan`, также `dmitri`, `denis`, `irina`) через sherpa-onnx или Vosk TTS
  (`vosk-model-tts-ru-0.7-multi`).
- **Голос владельца:** CAM++ (3D-Speaker) через sherpa-onnx.

## Установка

Проще всего — флешка, которая ставит Ubuntu Server сразу с Орфеем:
`scripts/make_usb.sh /dev/sdX`, подробности в [docs/usb.md](docs/usb.md).

Или вручную на чистый Ubuntu Server 24.04 или Debian 13 без графики
(как поставить систему — [docs/install-ubuntu-server.md](docs/install-ubuntu-server.md)).
Из корня репозитория:

```sh
sudo scripts/laptop.sh Europe/Moscow   # крышка, zram, часовой пояс, кириллица в консоли
scripts/install.sh                     # Ollama сразу на встроенной видеокарте (Vulkan)
```

Скрипт ставит системные пакеты, создаёт `.venv`, скачивает модели речи (~300 МБ),
ставит и настраивает Ollama, скачивает языковую модель (~2,5 ГБ) и кладёт
systemd-сервисы. После него нужно перелогиниться (добавлена группа `audio`).

### Планировщик (Planner)

Планы и заметки Орфей хранит в [Planner](https://github.com/arsenii-cmd/Planner) — отдельном
проекте с приложением для телефона и синхронизацией с компьютером. Орфей говорит с демоном
`plannerd` на этой же машине через `http://127.0.0.1:47211/api`:

```sh
git clone https://github.com/arsenii-cmd/Planner.git
install -Dm755 Planner/server/plannerd.py ~/.local/bin/plannerd
install -Dm644 Planner/server/quickparse.py ~/.local/bin/quickparse.py
systemctl --user enable --now plannerd orpheus-server   # юнит plannerd.service ставит scripts/install.sh
```

Юнит запускает `plannerd serve --local-only`: копия слушает только `127.0.0.1` и синхронизируется
с вашим Planner через его облачный режим (как её подключить — в README Planner, раздел
«Headless copy»). Без Planner всё остальное работает, а `ORPHEUS_PLANNER=-` выключает его совсем.

## Запуск

```sh
. .venv/bin/activate
python -m orpheus --stats chat     # текстом — проверить мозг и память
python -m orpheus --stats voice    # голосом, с микрофоном ноутбука
python -m orpheus server           # сервер для телефона (WebSocket, порт 8765)
python -m orpheus listen           # только распознавание речи
python -m orpheus memory           # что Орфей помнит  (--forget ID — забыть)
python -m orpheus notes [слова]    # заметки / поиск по ним

systemctl --user enable --now orpheus                   # голосовой режим при загрузке
systemctl --user enable --now plannerd orpheus-server   # или сервер для телефона
journalctl --user -u orpheus-server -f                  # лог
```

`--stats` печатает, сколько заняло распознавание, через сколько пришло первое
слово ответа и сколько токенов промпта модели пришлось прочитать.

В чате работают команды `/mem`, `/notes`, `/reset` (новый разговор), `/quit`.

## Что умеет

Обычные команды выполняет сама программа, без языковой модели: мгновенно и без выдумок.
От конца фразы до первого звука ответа проходит 0,6–1 с, из них ~0,3 с распознавание и ~0,4 с синтез.
Модель (2,5–6 с) — только собеседник: разговор, вопросы, советы, шутки. Планов, заметок и памяти она не видит
и ничего не записывает: это делает программа по командам ниже.

| Скажи | Что происходит |
| --- | --- |
| «Который час?», «Какое сегодня число?», «Какой день недели будет 1 октября?» | время и дата |
| «Сколько дней до Нового года?», «Сколько времени осталось до полуночи?», «…до 18:00?» | счёт дней, часов и минут |
| «Сколько будет 15 умножить на 37?», «20% от 3 000» | калькулятор |
| «Запиши тренировку в среду в 6 утра, 10 недель» | событие в Planner; части в любом порядке, повтор днями, неделями или месяцами. Записать в планы можно только командой «Запиши …» — на «добавь …» Орфей подскажет её |
| «Запиши тренировку» → «Время?» → «В 6 утра» → «Сколько раз?» → «Один раз» | чего не хватает, Орфей спросит; «отмена» — не записывать |
| «Запиши в чек-лист купить хлеб» | задача на сегодня; невыполненная переходит на следующий день |
| «Заметка: код от домофона 4521», «Сделай заметку: купить молоко», «Запиши, что …» | заметка в Planner (видна на телефоне и компьютере), слово в слово |
| «Сделай заметку про ремонт, купить краску» | заметка с заголовком «Ремонт» |
| «Прочитай мои заметки», «Найди заметку про вайфай», «Удали заметку про ремонт» → «Да» | заметки |
| «Запомни, что я люблю кофе без сахара», «Забудь, что я люблю кофе» | факты о вас |
| «Меня зовут Иван», «Как меня зовут?» | имя |
| «Что у меня завтра?», «Какие планы на неделю?», «Что у меня дальше?», «Сколько у меня завтра дел?» | планировщик |
| «Есть ли завтра русский в 10?», «Когда пробник?», «Во сколько заканчивается хакатон?», «Когда следующая тренировка?», «Какой день на неделе самый загруженный?» | ответ из планировщика |
| «Посмотри, что у меня в четверг, и если там пусто — добавь тренировку в 18», «Если я свободен завтра в 19, запиши кино» | план ставится, только если день (или это время) свободен; иначе — что там есть и «Добавить всё равно?» |
| «Напомни мне через 2 часа выпить таблетку», «Напомни завтра в 9 взять документы» | напоминание |
| «Отметь хлеб купленным», «Перенеси физику на завтра в 15», «Отмени завтра в 10 русский» → «Да» | правка планов |
| «Перенеси его на 14», «Нет, лучше на 15», «А второе удали» | то, о чём только что шла речь |
| «Удали все дела на завтра» → «Да» | всё за день, после подтверждения со списком |
| «Верни» | отмена последнего удаления, добавления или отметки |
| «Повтори», «Привет», «Спасибо», «Как дела?», «Что ты умеешь?», «Подбрось монетку» | мелочи |
| «Какая погода [завтра / вечером / на выходных / в Сочи]?», «Будет ли дождь?», «Как одеться?» | погода (Open-Meteo), по умолчанию для города из `ORPHEUS_CITY`; прогноз на 7 дней обновляется раз в 6 часов |
| «Кто такой Никола Тесла?», «Что такое фотосинтез?» | первые фразы статьи Википедии |
| «Найди в интернете …», «Сколько стоит биткоин?», «Какие новости?» | «Сейчас поищу», затем короткий ответ модели по выдаче DuckDuckGo (или своего SearXNG); если поиск не ответил — модель отвечает по своим знаниям, с оговоркой |
| «Какой курс доллара?», «А евро?», «Сколько будет 100 долларов в рублях?» | официальный курс ЦБ РФ |
| «А завтра?», «А в Сочи?», «А на выходных?» после погоды или планов | тот же вопрос про другой день или город |
| «Что у меня завтра и какая будет погода?», «Запомни …, и сделай заметку …» | две просьбы в одной фразе — обе |
| «Включи музыку», «Поставь таймер» | честное «пока не умею» |

В интернет Орфей ходит только к этим сервисам (Open-Meteo и его поиск городов, Википедия,
DuckDuckGo, ЦБ), через прокси из `ORPHEUS_PROXY`, если он задан; в «Личном» не ищет.
Удаление всегда спрашивает подтверждение, и «нет» значит нет.

Сценарии описаны шаблонами фраз в [`orpheus/intents_ru.txt`](orpheus/intents_ru.txt) — синтаксис как у
Home Assistant: `(а|б)` — одно из, `[а]` — можно пропустить, `{слот}` — любые слова. Чтобы научить
Орфея новой фразе, достаточно дописать шаблон; новый сценарий — это раздел в файле и метод
`do_<имя>` в [`orpheus/skills.py`](orpheus/skills.py).

## Как устроена скорость

На таком процессоре модель **генерирует** 5–10 токенов/с (этого хватает, чтобы
говорить вслух), но **читает** промпт всего со скоростью ~30–60 токенов/с. Если
на каждую фразу перечитывать системный промпт, память и историю (~1500 токенов),
ответ начнётся через 30+ секунд. Поэтому:

0. **Без модели, где можно.** Время, дата, счёт, заметки, планировщик, память — сценарии программы:
   доли миллисекунды на разбор фразы. Ответы программы не копятся в истории модели:
   ей передаётся только последний обмен, иначе первая же её реплика перечитывала бы их все (20–30 с).
1. **Модель всегда в памяти.** `OLLAMA_KEEP_ALIVE=-1`, прогрев при старте Орфея.
2. **Кэш префикса.** Ollama хранит KV-кэш прошлого запроса и заново считает только
   то, что отличается. Орфей строит промпт так, чтобы от реплики к реплике менялся
   только конец:
   - системный промпт не меняется в течение разговора — время и дата идут в начале
     реплики пользователя, а не в системном промпте;
   - история обрезается редко и сразу большим куском, а не по одной реплике.
3. **Один слот.** `OLLAMA_NUM_PARALLEL=1` — весь кэш принадлежит Орфею.
4. **Постоянный `num_ctx`.** Другой размер контекста заставляет Ollama перезагрузить модель.
5. **Потоковый вывод.** Первое предложение озвучивается, пока пишется второе.
6. **Меньше памяти на кэш.** `OLLAMA_FLASH_ATTENTION=1` + `OLLAMA_KV_CACHE_TYPE=q8_0`.

Замеры на Ryzen 5 3500U, 8 ГБ (Qwen3 4B, Q4_K_M), `python scripts/bench_llm.py`:

| | Процессор | Vega 8 (Vulkan) |
| --- | --- | --- |
| Чтение промпта | ~15 ток/с | ~70 ток/с |
| Генерация | ~7 ток/с | ~9 ток/с |
| Первое слово обычной реплики | 4–5 с | 1,5–2,5 с |
| Холодный старт (после перезагрузки) | ~60 с | ~10 с |

Поэтому установка сразу включает встроенную видеокарту (`scripts/setup_ollama.sh --vulkan`, драйвер
`mesa-vulkan-drivers`). Проверить, где работает модель, — `ollama ps` (столбец PROCESSOR должен быть `100% GPU`).

## Только голос владельца

Орфей может отвечать только вам: на телевизор, гостей и чужое «Орфей» он промолчит.
Сервер сверяет голос каждой фразы с записанным голосом владельца (`orpheus/voiceprint.py`:
модель CAM++, 28 МБ, ~35 мс на фразу, параллельно с распознаванием, так что ответ не задерживает).

1. В приложении: «Настройки → Мой голос», прочитать вслух пять фраз.
   Или на сервере по записям: `python -m orpheus voiceprint enroll a.wav b.wav …`.
2. Несколько дней пожить в режиме `log` (так по умолчанию): отвечает всем, а в журнале
   у каждой фразы — `голос 0.71`.
3. Порог (`ORPHEUS_SPEAKER_THRESHOLD`) — между своими оценками и чужими. В проверке на
   синтетических голосах владелец получал 0,56–0,82 (в том числе с шумом), чужие — не выше 0,47.
4. `ORPHEUS_SPEAKER=strict` — и Орфей отвечает только вам. Приложение умеет включать строгий
   режим только в наушниках.

Короткие фразы («да», «стоп») не проверяются: по секунде голоса не судят. Голос подстраивается
понемногу сам (утренний, простуженный, другая комната), но не уходит далеко от записанного.
Это защита от чужих голосов, а не замок: запись вашего голоса он пропустит.

`python -m orpheus voiceprint` — что записано; `… score a.wav` — оценить запись; `… reset` — забыть.

## Проверка

- `python -m pytest` — тесты (`pip install pytest`).
- `scripts/bench_speech.py` — 270 фраз в 68 диалогах, сказанных «как в жизни» (оговорки, поправки,
  разговорные слова), с проверкой того, что на самом деле оказалось в планировщике.
- `scripts/bench_tools.py`, `scripts/bench_dialogs.py` — все сценарии и целые разговоры с настоящей моделью.
- `scripts/bench_voice.py` — сквозная проверка: синтез голоса → распознавание → ответ.
- `scripts/bench_stt.py samples/` — точность распознавания на своём голосе (WER, RTF).

## Настройки

Переменные окружения; для сервиса — строками `Environment=` в его drop-in: `systemctl --user edit orpheus-server`
(или `orpheus` для голосового режима). Drop-in переживает переустановку юнитов через `scripts/install.sh`.

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `ORPHEUS_MODEL` | `huihui_ai/qwen3-abliterated:4b-instruct-2507-q4_K_M` | Модель в Ollama |
| `ORPHEUS_CTX` | `4096` | Размер контекста (тот же, что в `setup_ollama.sh`) |
| `ORPHEUS_TEMPERATURE` | `0.6`, у Gemma `0.2` | Креативность ответов |
| `ORPHEUS_LLM_THREADS` | авто | Потоки для модели |
| `ORPHEUS_THINK` | — | `0`/`1` только для гибридных моделей вроде `qwen3:4b` и Gemma 4 (лучше `0`) |
| `ORPHEUS_BATCH` | `128` | Размер пакета при чтении промпта |
| `ORPHEUS_IDLE_RESET` | `600` | Через сколько секунд тишины начинать новый разговор |
| `ORPHEUS_WAKE` | — | Слово активации для голосового режима, например `орфей`; без него отвечает на всё |
| `ORPHEUS_SPEAKER` | `log` | Голос владельца: `off` — не сверять; `log` — сверять и писать оценку в журнал; `strict` — отвечать только владельцу |
| `ORPHEUS_SPEAKER_THRESHOLD` | `0.5` | Порог сходства с голосом владельца (0–1) |
| `ORPHEUS_FOLLOW_UP` | `8` | Сколько секунд после ответа можно продолжать без слова активации |
| `ORPHEUS_VOICE` | `vits-piper-ru_RU-ruslan-medium` | Голос: папка Piper или модель Vosk TTS с номером диктора, например `vosk-model-tts-ru-0.7-multi:3` |
| `ORPHEUS_SPEED` | `1.0` | Скорость речи (больше — быстрее) |
| `ORPHEUS_TTS_THREADS` | `1` | Потоки синтеза (остальные ядра нужны модели) |
| `ORPHEUS_MIC` | системный | Номер или имя микрофона (`python -m sounddevice` покажет список) |
| `ORPHEUS_SILENCE` | `0.6` | Пауза, после которой фраза считается законченной |
| `ORPHEUS_VAD_THRESHOLD` | `0.5` | Чувствительность VAD; выше — меньше реагирует на шум |
| `ORPHEUS_MIN_SPEECH` / `ORPHEUS_MAX_SPEECH` | `0.25` / `20` | Границы длины фразы, с |
| `ORPHEUS_THREADS` | число ядер | Потоки распознавания |
| `ORPHEUS_DB` | `~/.local/share/orpheus/orpheus.db` | База памяти и заметок |
| `ORPHEUS_MODELS` | `~/.local/share/orpheus/models` | Модели речи |
| `ORPHEUS_OLLAMA` | `http://127.0.0.1:11434` | Адрес Ollama |
| `ORPHEUS_PLANNER` | `http://127.0.0.1:47211/api` | Локальный API Planner; `-` — без планировщика |
| `ORPHEUS_PROXY` | — | Прокси для погоды и поиска; пусто — напрямую, `-` — без интернета |
| `ORPHEUS_CITY` | `Москва` | Город для погоды, когда город не назван |
| `ORPHEUS_SEARXNG` | — | Свой SearXNG (`http://127.0.0.1:8888`): поиск сначала в нём, запасной — DuckDuckGo |
| `ORPHEUS_ALLOW` | локальная сеть | Адреса, с которых сервер принимает телефон |
| `ORPHEUS_TOKEN_FILE` | `~/.config/orpheus/voice-token` | Токен, который должен прислать телефон (если файл есть) |

Если фразы обрезаются посередине — увеличьте `ORPHEUS_SILENCE` до 0.8–1.0.
Если реагирует на вентилятор — поднимите `ORPHEUS_VAD_THRESHOLD`.

## Устройство кода

| Файл | Что делает |
| --- | --- |
| `orpheus/__main__.py` | Команды `voice`, `server`, `chat`, `listen`, `memory`, `notes`, `voiceprint`, `warmup` |
| `orpheus/server.py` | Сервер для телефона (WebSocket), [протокол](docs/android-protocol.md) |
| `orpheus/brain.py` | Системный промпт, история разговора, раскладка под кэш |
| `orpheus/commands.py` | Команды «Запиши …», «Запиши в чек-лист …», «Заметка …» |
| `orpheus/intents.py`, `orpheus/intents_ru.txt` | Шаблоны фраз, которые выполняет программа |
| `orpheus/skills.py` | Сценарии программы: что делать с каждой фразой |
| `orpheus/planner.py` | Planner (события, задачи, заметки) через его локальный API |
| `orpheus/calc.py`, `orpheus/numbers.py` | Калькулятор; числа, время и даты словами для голоса |
| `orpheus/memory.py`, `orpheus/vectors.py` | SQLite: факты, заметки, разговоры; поиск по словам и по смыслу |
| `orpheus/secure.py` | Шифрование «Личного» (ключ только на телефоне) |
| `orpheus/voiceprint.py` | Голос владельца |
| `orpheus/weather.py`, `orpheus/web.py`, `orpheus/search.py` | Погода, Википедия, поиск, курсы валют |
| `orpheus/llm.py` | Потоковый клиент Ollama без зависимостей |
| `orpheus/stt.py`, `orpheus/audio.py` | Распознавание речи (GigaAM v3), микрофон и Silero VAD |
| `orpheus/speech.py` | Синтез речи и нарезка ответа на предложения |
| `orpheus/config.py` | Все настройки |
| `scripts/` | Установка, загрузка моделей, бенчмарки |
| `android/` | Приложение для телефона ([android/README.md](android/README.md)) |
