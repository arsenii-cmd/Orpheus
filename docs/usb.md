# Флешка, которая ставит Ubuntu Server сразу с Орфеем

`scripts/make_usb.sh` берёт официальный образ Ubuntu Server 24.04 и добавляет в него
ответы для установщика, сам Орфей и модели: распознавание речи, голос и две
языковые модели (~4,6 ГБ): Qwen3‑4B (по умолчанию) и Qwen2.5‑3B (быстрее, но слабее).
А ещё системные пакеты, Python-библиотеки и сама Ollama (без CUDA, ~40 МБ), так что
**ноуту интернет не нужен вообще**: ни при установке, ни при первом запуске.
Весь образ — около 8 ГБ.

- `ORPHEUS_BUNDLE_MODELS=0` — без моделей, ноут скачает их сам при первом запуске.
- `ORPHEUS_BUNDLE_PACKAGES=0` — без пакетов и Ollama, их тоже скачает ноут.

В образе нет ни одного секрета. Сеть (с Wi-Fi и его паролем), пользователь с паролем
и SSH вводятся в обычных экранах установщика прямо на ноуте. Всё остальное
автоматически: разметка диска, копирование Орфея и настройка при первом запуске.

## Что нужно

- Компьютер с Linux (или WSL на Windows), интернетом и `xorriso curl python3 pip git zstd`:
  Ubuntu/Debian — `sudo apt install xorriso curl python3-pip git zstd`,
  Arch — `sudo pacman -S --needed libisoburn curl python-pip git zstd`.
- Флешка от 16 ГБ (32 ГБ — с запасом). **Всё на ней сотрётся.**

## Сборка

Из корня репозитория:

```sh
lsblk                          # найди флешку по размеру, например /dev/sdb
scripts/make_usb.sh /dev/sdb   # собрать образ и записать его на флешку
```

Скрипт спросит только часовой пояс (по умолчанию `Europe/Moscow`) и GitHub-логин,
чьи публичные SSH-ключи подставить на экран SSH.

Официальный образ (~3 ГБ), модели, пакеты и Ollama скачиваются один раз в
`~/.cache/orpheus-usb` и проверяются по контрольным суммам, так что пересборка
занимает минуту. Прерванная загрузка продолжается с того же места. Перед записью скрипт покажет флешку
и попросит ещё раз ввести имя устройства. Системный диск он не тронет: пишет только
на съёмные и USB-устройства.

Без `/dev/sdX` скрипт только соберёт `orpheus-ubuntu-server.iso`. Его можно
записать и с Windows через [Rufus](https://rufus.ie) — на вопрос о режиме выбрать
**DD**.

## Установка

1. Вставь флешку в ноут Орфея, загрузись с неё (F12 / F9 / Esc — меню загрузки).
2. В меню выбери «Try or Install Ubuntu Server». Если установщик спросит
   «Continue with autoinstall? (yes|no)» — напиши `yes`.
3. **Network** — подключись кабелем или выбери Wi-Fi и введи его пароль (нужно для
   `ssh` и обновлений; для установки Орфея сеть не нужна — можно пропустить). Done.
4. **Profile** — имя, имя машины (`orpheus`, в сети будет `orpheus.local`),
   логин и пароль. Done.
5. **SSH** — «Install OpenSSH server» уже отмечен, ключи с GitHub уже подставлены. Done.
6. ⚠️ Дальше установщик **сам стирает весь внутренний диск** ноута и ставит систему.
   Минут через 10–20 ноут перезагрузится сам. Вынь флешку.
7. Первый запуск (5–15 минут): системные пакеты, Python-библиотеки, Ollama и
   модели ставятся с того, что было на флешке. На экране идёт лог; с другого компьютера:
   `ssh логин@orpheus.local`, затем `journalctl -u orpheus-firstboot -f`.
8. В конце ноут перезагрузится ещё раз — и Орфей запустится сам.

Если первый запуск прервался, он повторится при следующей загрузке.

## Что оказывается на ноуте

- Ubuntu Server 24.04 на весь диск (без LVM), OpenSSH, твой пользователь.
- `~/Orpheus` — код в том виде, в каком он был у тебя при сборке флешки (с
  незакоммиченными правками).
- Всё из `scripts/laptop.sh`: крышка не усыпляет, zram, часовой пояс, кириллица в консоли.
- Модели речи, Ollama с настройками на скорость, языковая модель.
- Сервис `orpheus` (голосовой режим), который стартует при загрузке.

Проверка после установки:

```sh
cd ~/Orpheus && . .venv/bin/activate
python -m orpheus --stats chat
python scripts/bench_llm.py
journalctl --user -u orpheus -f
```

## Сравнить две языковые модели

```sh
cd ~/Orpheus && . .venv/bin/activate
python scripts/bench_llm.py                                          # Qwen3-4B
ORPHEUS_MODEL=qwen2.5-3b-abliterated python scripts/bench_llm.py     # Qwen2.5-3B
ORPHEUS_MODEL=qwen2.5-3b-abliterated python -m orpheus --stats chat  # поговорить, проверить память
```

Чтобы Орфей всегда работал на Qwen2.5‑3B, выполни `systemctl --user edit orpheus`, впиши
`[Service]` и строку `Environment=ORPHEUS_MODEL=qwen2.5-3b-abliterated`, затем
`systemctl --user restart orpheus`.
