# Орфей для Android

**Русский** · [English](README.en.md)

Телефон как умная колонка в кармане: приложение передаёт фразу серверу Орфея и проигрывает
ответ его голосом. Позвать Орфея можно двумя способами:

- **Касание** (по умолчанию): зажать сенсор Bluetooth-наушника. Орфей выбирается системным
  «цифровым помощником», и нажатие на наушник открывает разговор. Между разговорами микрофон
  выключен: батарея не тратится, музыка в наушниках не портится.
- **Слово**: приложение в фоне ждёт «Орфей» (Vosk, офлайн, прямо на телефоне), по нему пикает и
  слушает фразу. Микрофон открыт всегда.

После ответа Орфей несколько секунд слушает продолжение без повторного вызова.
Всё, кроме слова активации, делает сервер; протокол — [../docs/android-protocol.md](../docs/android-protocol.md).

## Возможности

- Работает при закрытом приложении и выключенном экране: foreground-служба с постоянным
  уведомлением (кнопки «Говорить» и «Выключить»).
- **Микрофон наушников.** Когда подключены Bluetooth-наушники, приложение слушает через них: телефон
  может лежать в кармане.
- **Строгий режим в наушниках.** В наушниках Орфей отвечает только голосу владельца, без них — всем.
  Голос записывается в «Настройки → Мой голос»: пять фраз вслух.
- **«Личное».** Кнопка открывает раздел с отдельной зашифрованной памятью; ключ хранится в Android
  Keystore и передаётся серверу только при подключении.
- Команду можно сказать сразу, без паузы: «Орфей, какая погода». Всё, что прозвучало после слова,
  берётся из буфера и не теряется.
- Пока Орфей говорит, слово активации не слушается, чтобы он не будил сам себя. Перебить его можно
  кнопкой «Говорить».
- Голос ответа: мужской или женский. Чат с историей разговора, её можно очистить.

## Интерфейс

| Сфера | Что происходит |
| --- | --- |
| тусклый уголёк | Выключен |
| синяя, дышит внутри мерцающего кольца | Ждёт вызова |
| голубая, из неё растут лучи-спектр в такт голосу | Слушает фразу (сигнал «начал слушать»: два восходящих тона) |
| фиолетовая, вокруг летают кометы по наклонным орбитам | Фраза передана (сигнал «принял»: два нисходящих тона), ждёт ответа |
| золотая, вокруг проявляется лира, струны дрожат | Говорит ответ |
| бирюзовая, лучи и кольцо | Слушает продолжение без вызова (время настраивается) |

Каждая смена состояния перетекает, а не переключается: форма, свет, цвет неба и подпись меняются
пружинами, из сферы расходится ударная волна, телефон слегка вибрирует. Ответ проявляется в чате
по словам, пока приходит. Если в системе выключены анимации, движение останавливается, а цвета и
состояния остаются.

## Сборка

Нужны Android SDK (platform 36) и JDK 17. Из этой папки:

```sh
scripts/fetch_wake_model.sh     # один раз: модель Vosk (~45 МБ) в assets
./gradlew assembleRelease       # app/build/outputs/apk/release/app-release.apk (~60 МБ)
adb install -r app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest     # тесты логики
```

Адрес сервера и токен можно встроить в сборку через `local.properties` (он не попадает в git):

```properties
orpheus.server=wss://your.domain/ws
orpheus.token=<токен сервера>
```

Без них приложение спросит адрес и токен в настройках. Сборка только под `arm64-v8a`. Релиз
подписан отладочным ключом.

## Первый запуск

1. «Включить Орфея» и разрешить микрофон и уведомления.
2. «Разрешить работу в фоне без ограничений»: без этого часть телефонов (Xiaomi, Samsung, Huawei)
   через какое-то время убивает службу.
3. Для касания: «Выбрать помощником» → Орфей; в приложении наушников для «Касания и удержания»
   выбрать «Цифровой помощник» (у Galaxy Buds — в Galaxy Wearable).
   Если при касании телефон спросит, чем выполнить, — «Орфей», «Всегда».
4. Для слова: если Орфей срабатывает на посторонние слова, поднимите «Строгость слова», если не
   отзывается — опустите. При первом включении модель слова распаковывается несколько секунд.

После перезагрузки телефона Android не даёт службам с микрофоном запускаться самим, так что Орфея
надо включить заново.

## Проверка без настоящего сервера

```sh
pip install websockets numpy sherpa-onnx
python tools/mock_server.py --save /tmp/phrases
```

В приложении: «Настройки» → адрес `ws://<IP этого компьютера>:8765/ws`, токен пустой.
Мок отвечает голосом Piper, сколько секунд длилась фраза. С `--save` он сохраняет
каждую принятую фразу в WAV, чтобы услышать, что именно прислал телефон.

## Устройство

| Файл | Что делает |
| --- | --- |
| `AssistantMachine.kt` | Состояния и переходы (ждёт → слушает → думает → говорит → продолжение), таймауты. Чистый Kotlin, покрыт тестами |
| `OrpheusService.kt` | Служба: микрофон, слово активации, передача звука, уведомление |
| `Assistant.kt` | Цифровой помощник (VoiceInteractionService) и вызов с наушника |
| `Headset.kt` | Микрофон Bluetooth-наушников |
| `WakeWord.kt` | Грамматика Vosk: «орфей» и похожие слова-ловушки, выбор слова по уверенности |
| `Audio.kt` | VAD по громкости, фильтр гула, кольцевой буфер на 10 с, PCM |
| `ServerLink.kt` / `Protocol.kt` | WebSocket с переподключением, сообщения протокола |
| `KeyVault.kt` | Ключ «Личного» в Android Keystore |
| `Sound.kt` | Проигрывание ответа, звуковые сигналы (синтезируются, без файлов) |
| `ui/Orb.kt` | Сфера: жидкое тело, лучи, кометы, лира, ударная волна. Один кадровый таймер, рисование без перекомпоновки |
| `ui/Backdrop.kt` | Небо: полярное сияние в цвет состояния, звёзды на трёх глубинах |
| `ui/Screens.kt` | Главный экран, чат, кнопки, настройки, запись голоса |
| `ui/Motion.kt` | Общие пружины, кинетический текст, блик по тексту, нажатие с пружиной, ступенчатые появления |
| `ui/Theme.kt` | Цвета состояний, шрифты (Unbounded и Manrope, OFL, `res/font`, лицензии в `licenses/`) |

### Посмотреть интерфейс без телефона

`tools/ui-preview` собирает тот же код `ui/` на Compose Desktop и проигрывает
сценарий (выключен → включён → слушает → думает → отвечает → настройки) кадр за кадром.
Нужны только JDK и интернет до Maven Central, Android SDK не нужен:

```sh
cd tools/ui-preview
gradle render -Pout=/tmp/frames            # 720 кадров PNG, 400 × 860 dp
ffmpeg -framerate 30 -i /tmp/frames/f%05d.png -pix_fmt yuv420p orpheus-ui.mp4
```

Код `ui/` поэтому пишется только на общем Compose (foundation, animation, material3),
без Android API: всё платформенное (шрифты из `R`, настройка анимаций) передаётся
из `MainActivity`. Типы приложения, которые нужны экрану, в стенде заменены
заглушками (`tools/ui-preview/src/main/kotlin/dev/arco/orpheus/Stubs.kt`): при изменении
`Settings`, `Phase` или `Line` их нужно поправить и там.
